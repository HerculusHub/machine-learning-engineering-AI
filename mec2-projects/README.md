mec2-projects
Repository for Machine Learning and AI Bootcamp projects

How to submit mini-projects
Open a new Colab notebook by going to https://colab.research.google.com/.
On the entry menu, click on the 4th tab from the left that says GitHub.
Paste the following url into the search field: https://github.com/springboard-curriculum/mec2-projects
If prompted, log into Colab and authorize GitHub to connect to your Colab account.
Click on the mini-project file you're going to work on.
Complete all parts of the mini-project.
When you're done, click on File > Save a copy in GitHub in the navigation bar.
You'll notice Colab automatically clones the mec2-projects folder to your repository. Click OK when you're ready to save the mini-project to your repository.
Go to the url corresponding to the path of the mini-project saved in your GitHub repository.
