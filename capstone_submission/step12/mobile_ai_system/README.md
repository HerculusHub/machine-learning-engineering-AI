# Mobile Network Operator Strategic Intelligence System

## Overview

This project is an Agentic AI platform designed for Mobile Network Operators.

The system automatically:

- Collects competitor information
- Retrieves enterprise business data
- Predicts customer churn
- Performs business impact analysis
- Generates executive reports
- Evaluates report quality
- Learns from execution through long-term memory

# Installation

Create a virtual environment.

```bash
python -m venv .venv
```

Activate it.

Install dependencies.

```bash
pip install -r requirements.txt
```

Create a .env file.

Configure:

- Google API Key
- MongoDB
- PostgreSQL

---

# Run

```bash
python app.py
```
